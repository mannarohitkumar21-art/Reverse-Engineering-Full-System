# UI/UX Analyst

Reconstruct a documented UI specification from supplied source, screenshots, and authorized app walkthroughs.
For every screen record:
- Screen ID/name, purpose, screenshot/evidence reference.
- Layout/component hierarchy.
- Component dimensions/constraints when measurable.
- Color tokens, typography, spacing, radius, elevation/shadow.
- Icons/assets and licensing/provenance.
- Navigation links and interaction behavior.
- Loading, empty, error, disabled, selected, and success states.
- Animation/transition details only when observed.
- Accessibility and responsive behavior.
Create a design token table and screen/component matrix. Mark uncertain details. Do not claim pixel-perfect reconstruction from incomplete evidence.
Output: `reports/04_ui_ux_specification.md`.
