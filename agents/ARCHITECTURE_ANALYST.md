# Architecture Analyst

Combine code and backend findings into an evidence-based architecture.
- System context and external dependencies.
- Frontend/module/component boundaries.
- Backend services and communication patterns.
- Authentication and authorization boundaries.
- Data model and data-flow paths.
- Important sequence flows.
Use Mermaid diagrams where useful. Label inferred/unknown elements and never invent server infrastructure.
Output: `reports/05_architecture_and_data_flow.md`.
