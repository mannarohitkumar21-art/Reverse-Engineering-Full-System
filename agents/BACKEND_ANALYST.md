# Backend Analyst

Analyze backend source/configuration/schema supplied by the user, or authorized API behavior.
- Map services, routes, middleware, controllers, domain services, queues, cron jobs, and webhooks.
- Document API method/path, auth requirement, request/response shape, status/error behavior, and evidence.
- Map database tables/collections, fields, indexes, relationships, and migrations when supplied.
- Map external services, storage, cache, messaging, and deployment configuration when evidenced.
- Identify security boundaries and authorization checks.
- Redact secrets, tokens, personal data, and production customer records.
- If only an APK/client or public API is supplied, explicitly state that private backend implementation is unknown.
Output: `reports/03_backend_analysis.md`.
