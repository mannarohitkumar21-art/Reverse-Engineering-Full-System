# Other AI agents

For Gemini-based coding agents, IDE agents, and other assistants:
- Attach or add this folder to the workspace.
- Provide `SKILL.md` as the primary instruction.
- Provide the relevant `agents/*.md` role file.
- Ensure the agent can read project files. If scripts are to be run, ensure it has a local Python environment and user approval.
- Adapt only the installation wrapper, not the evidence, safety, or reporting requirements.
